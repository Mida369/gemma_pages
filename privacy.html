Privacy Policy – Gemma

Last updated: 9 October 2026

Gemma is a private, personal AI assistant used only by its developer, for personal and non-commercial purposes. It is not offered to the public. This policy explains how Gemma handles the Google account data it is authorized to access.

1. Data accessed

When the account owner authorizes it, Gemma accesses data in the owner's own Google account through Google APIs: Gmail (read, draft and send email), Google Calendar, Google Drive, Google Docs, Google Sheets and Google Contacts (read-only). Gemma accesses this data only to carry out requests made by the account owner.

2. How data is used

Data is used only to provide the features the account owner asks for, such as summarizing unread email, drafting and sending a message after the owner's confirmation, adding a calendar event, or saving a file to Drive. Data is not used for advertising, profiling, or any other purpose.

3. Storage and security

Data is processed on a private server controlled by the developer. The authorization token is stored on that server with restricted file permissions. Gemma may keep short summaries of conversations on that server to remain useful to its owner.

4. Third-party AI services

To generate responses, text that the owner asks Gemma to work on (for example the text of an email or a document) may be sent to third-party AI model providers for processing. This is done only to fulfil the owner's request.

5. Sharing and selling

Gemma does not sell Google user data, does not share it with other people, and does not transfer it to third parties except as described in section 4.

6. Google API Services User Data Policy

Gemma's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. No human reads Google user data except when the account owner is reading it, or where required by law.

7. Retention and deletion

The account owner can revoke Gemma's access at any time from the Google account permissions page (myaccount.google.com/permissions) and can delete the stored authorization token and any stored data from the server.
